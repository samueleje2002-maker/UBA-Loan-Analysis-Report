UBA Loan Analysis Report Dashboard

📊 Project Overview

This project is an interactive Bank Loan Analysis Dashboard built with Power BI during my Syntecx Hub Virtual Data Analytics Training.

The dashboard analyzes loan applications, funded amounts, repayment performance, customer financial behavior, and loan risk classification to provide actionable business insights for decision-making.

---

🎯 Objectives

- Analyze loan application trends
- Track funded amount vs amount received
- Classify loans into Good Loans and Bad Loans
- Identify repayment performance
- Explore customer and loan behavior across different dimensions

---

🛠 Tools Used

- Power BI
- Power Query Editor
- Microsoft Excel

---

📈 Key Metrics

- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average Debt-to-Income Ratio (DTI)

---

📌 Dashboard Features

Summary Dashboard

- Good Loan vs Bad Loan Analysis
- Loan Status Breakdown
- KPI Cards

Overview Dashboard

- Loan Applications/Total funded amount and received amount by State
- Loan Applications/Total funded amount and received amount by Purpose
- Loan Applications, funded amount and received amount by Employment Length
- Loan Applications, funded amount and received amount by Home Ownership
- Loan Applications,funded amount and received amount by Term

Customer Details Dashboard

- Detailed customer loan analysis
- Interactive filters and slicers

---

💡 Key Insights

- Good loans accounted for over 86% of total issued loans
- Total amount received exceeded total funded amount
- Debt consolidation recorded the highest loan application volume
- Home ownership influenced loan behavior significantly
